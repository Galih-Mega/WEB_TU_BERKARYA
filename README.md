# TU BERKARYA - Smart School System

Sistem Manajemen Informasi Terpadu untuk Tata Usaha (TU) Sekolah, diawali dari **SDN Gambirono 03** dan dirancang untuk dapat menaungi banyak sekolah mitra.

## 🚀 Fitur Utama
* **Mutasi Siswa**: Monitoring data siswa mutasi masuk dan keluar antar sekolah.
* **PPDB Terpadu**: Formulir pendaftaran siswa baru multi-sekolah.
* **Cetak Bukti PDF**: Generate otomatis bukti pendaftaran lengkap dengan KOP Resmi instansi/sekolah tujuan.

## 🛠️ Tech Stack
* **Frontend**: HTML5, Tailwind CSS, FontAwesome Icons
* **Library**: `html2pdf.js` (Generate PDF)
* **Hosting Target**: Vercel
* **Database Target**: Firebase Firestore & Storage
